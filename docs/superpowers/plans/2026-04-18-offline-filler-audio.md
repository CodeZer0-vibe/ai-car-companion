### Task 2: FillerBank + FillerPlayer

**Spec (exact quote):**

> - `engine/audio/FillerPlayer.ts` — single-Sound wrapper via `expo-audio`. Exposes `playClip(requireId: number)`, `stop()`, `isPlaying()`, `dispose()`. Reuses the audio session already configured by `AppSessionRuntime.ts` via `setAudioModeAsync(RECORDING_AUDIO_MODE)` — does NOT re-configure the session.
> - `engine/audio/FillerBank.ts` — `Record<Bucket, number[]>` where values are Metro `require()` ids. Shuffle-bag picker. All `require()` calls static at top of file so Metro bundles MP3s.
>
> **Rule 2:** Filler interrupts other filler. Only one filler clip plays at a time; newer trigger calls `FillerPlayer.stop()` then `playClip()`.
> **Rule 6:** No repeats within a bucket until all variants played. `FillerBank` maintains a shuffle-bag per bucket; `pick(bucket)` pops a random unused clip and refills the bag when empty.

**Files:**

- CREATE: `engine/audio/FillerPlayer.ts`
- CREATE: `engine/audio/FillerBank.ts`

**Contract:** Contract 4 (hook/service with internal state + cleanup) — these are stateful services with `dispose()`.

**Deliverables:**

Must exist (L1):

1. `FillerPlayer` class → `engine/audio/FillerPlayer.ts`
2. `playClip(requireId: number): Promise<void>` method → `FillerPlayer.ts`
3. `stop(): void` method → `FillerPlayer.ts`
4. `isPlaying(): boolean` method → `FillerPlayer.ts`
5. `dispose(): void` method → `FillerPlayer.ts`
6. `FillerBank` with `pick(bucket: FillerBucket): number | null` → `engine/audio/FillerBank.ts`
7. `FillerBucket` type export → `engine/audio/FillerBank.ts`
8. Static `require()` for all 18 MP3s (by filename from spec §Assets) at top of `FillerBank.ts`

Must work (L2):

9. `playClip` stops any previous clip before loading the new one (no overlap within FillerPlayer).
10. `isPlaying()` returns `true` between `playClip` invocation and playback completion, `false` otherwise.
11. `pick(bucket)` never returns the same clip twice in a row from the same bucket until the bag is exhausted, then refills.
12. `pick(bucket)` returns `null` if the bucket is empty (defensive).
13. `dispose()` unloads the current sound and clears any load-in-flight state — no leaks.
14. `FillerPlayer` reports errors via `RuntimeTelemetry.error("filler_player_<stage>_failed", err)` — never silently swallows.

Must NOT exist:

15. No call to `setAudioModeAsync` inside `FillerPlayer` (spec: reuses session).
16. No `any`, `// TODO`, stub returns.

### Task 5: FillerCoordinator + runtime wiring

**Spec (exact quote):**

> **Triggers (verbatim from spec §Triggers):**
>
> | Bucket          | Trigger condition                                                                                                                                      | Playback                                     |
> | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------- |
> | COLD_START      | After `bootstrapRuntime` resolves and before `Promise.all([connect, startAudioPipeline])`. Cancelled if Gemini `onConnectionChange(true)` fires first. | `sfx-boot-chirp` → one random `cold-start-*` |
> | NETWORK_LOST    | `NetInfo` reports `isConnected=false` (with 2s debounce).                                                                                              | one random `network-lost-*`                  |
> | RECONNECTING    | `GeminiCallbacks.onReconnectScheduled(attempt)` fires with `attempt >= 2`. Max once per 15s.                                                           | one random `reconnecting-*`                  |
> | BRAIN_DOWN      | `GeminiCallbacks.onReconnectExhausted` fires.                                                                                                          | `sfx-reconnect-ping` → one `brain-down-*`    |
> | API_KEY_MISSING | `AppSessionRuntime.start()` reaches empty-`API_KEY` branch. Played alongside existing UI error.                                                        | `api-missing-1`                              |
> | IDLE_FILLER     | Live session active AND no user/Gemini audio for ≥ 90s. Checked by 1s interval timer. Max once per 90s.                                                | one random `idle-*`                          |
>
> - `engine/runtime/FillerCoordinator.ts` — subscribes to runtime events, enforces playback rules, calls `FillerPlayer.playClip`. Exposes `isFillerPlaying()` for mic gate.
> - `engine/runtime/AppSessionRuntimeTypes.ts` — add `fillerCoordinatorRef: RefObject<FillerCoordinator | null>`. Update `AppSessionRuntimeDeps`.
> - `engine/runtime/AppRuntimeBootstrap.ts` — construct `FillerPlayer`, `NetworkMonitor`, `FillerCoordinator` after the existing bootstrap I/O fan-out. Assign to refs.
> - `engine/runtime/AppSessionRuntime.ts`:
>   - When `API_KEY` is empty (line 33–38 region), call `fillerCoordinatorRef.current?.trigger("API_KEY_MISSING")` alongside the existing `setSpeechText`.
>   - After `bootstrapRuntime` resolves and before the `Promise.all([connect, startAudioPipeline])` call, call `fillerCoordinatorRef.current?.trigger("COLD_START")`.
>   - Start `NetworkMonitor`. Start `idleFillerTimer` (1s interval, checks last-audio timestamp).
> - `engine/runtime/AppRealtimeHandlers.ts`:
>   - In the `onAudioChunk` mic callback, check `fillerCoordinatorRef.current?.isFillerPlaying() === true` and drop the frame if so (same treatment as `playbackControllerRef.current?.isSpeaking()`).
>   - In `registerGeminiRuntimeCallbacks`, pipe the new `onReconnectScheduled` → `fillerCoordinator.onReconnectScheduled`, existing `onReconnectExhausted` → `fillerCoordinator.trigger("BRAIN_DOWN")`, and in the Gemini audio-chunk path call `fillerCoordinator.onLiveAudioArrived()`.
>   - In the existing `onConnectionChange(true)` branch, call `fillerCoordinator.onGeminiReady()` so COLD_START state clears.
> - `engine/runtime/AppShutdownCoordinator.ts` — dispose `FillerCoordinator` (which disposes `FillerPlayer` + `NetworkMonitor`).
> - **File-level lock:** No changes to `PlaybackController.ts` or `StreamingPlayer.ts`.
>
> **Rules:**
>
> 1. Never overlap with live voice. Before `FillerCoordinator.trigger(bucket)` picks a clip, checks `playbackControllerRef.current?.isSpeaking() === false`. If speaking, filler is dropped (not queued).
> 2. Filler is preempted by live voice. `onGeminiAudioChunk` calls `fillerCoordinator.onLiveAudioArrived()` → `FillerPlayer.stop()`.
>
> **Rate limits:**
>
> - RECONNECTING max once per 15s
> - IDLE_FILLER triggers after ≥ 90s silence, max once per 90s
>
> **Idle edge case:** `FillerCoordinator` receives `lastMicChunkAtRef` at construction and defers if `Date.now() - lastMicChunkAtRef.current < 2000`; re-polls after 5s.

**Files:**

- CREATE: `engine/runtime/FillerCoordinator.ts`
- MODIFY: `engine/runtime/AppSessionRuntimeTypes.ts`
- MODIFY: `engine/runtime/AppRuntimeBootstrap.ts`
- MODIFY: `engine/runtime/AppSessionRuntime.ts`
- MODIFY: `engine/runtime/AppRealtimeHandlers.ts`
- MODIFY: `engine/runtime/AppShutdownCoordinator.ts`

**Contract:** Contract 6 (architecture — cross-cutting, 6 files) + Contract 4 per new service.

## Success gates (per spec §Success criteria)

1. Cold-start silence eliminated: first audible clip ≤ 1.5s of bootstrap.
2. Airplane-mode test passes end-to-end.
3. Mic never records filler back into Gemini (manually verified: turn off airplane mode during filler, confirm no echo in next Gemini turn).
4. No clip repeats within a bucket before siblings exhausted.
5. Filler never overlaps live voice.
6. Cold-boot to first audible clip ≤ 1.5s on a mid-tier iOS device (measured device-side, not simulator).
